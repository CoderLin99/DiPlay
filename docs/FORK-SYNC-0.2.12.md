# 2026-10-05 上游与吉利适配同步

源码版本：`0.2.12-geely.1`，versionCode `34`。本次同步本身不发布安装包，之前的 `0.2.11-geely.4` APK 不包含本页更新。

合并基线：官方 [2fc876e](https://github.com/shihabal3amri/DiPlay/commit/2fc876e578eba3905a5b873e3c2dbd74f498433a)，吉利分支 [8f53b27](https://github.com/carlito12345/DiPlay/commit/8f53b27b3168aedb661e9f9bb7122ea344b75ada)。

## 新增与修正

- 无线连接增加热点就绪检测、启动重试与回退，并支持已有 Wi-Fi 网络连接；具体方式仍取决于车机系统能力。
- 自定义分辨率范围扩展至 30%–160%，校验实际解码能力；支持画面实时调整、日夜模式及独立状态栏/导航栏设置。
- 吉利导航语音增加输出设备枚举、设备编号输入和试听。优先使用原车导航用途，不再为未配置的新用户强制通道 14；已保存的旧通道继续保留。设备选择是路由请求，实际发声位置需要装车试听。
- 没有系统 Opus 解码器时增加软件解码；改进画面积压处理和通话挂断后的音频恢复。不能据此认定手机出声、微信蓝牙录音无声已经解决。
- 吉利 HUD 提示增加尺寸适配和内容缩放；方向盘服务诊断增加绑定、注册与授权失败原因。
- 保留上游 BYD 仪表地图、方向盘地图缩放等功能。博越 L 完整地图飞屏仍缺少可验证的仪表区域与权限接入，不把 BYD 专属适配当作吉利适配。

## 本分支保留的行为

- 原车蓝牙音频兼容模式、默认关闭的原厂蓝牙交接，以及仅在手机请求后执行一次的交接逻辑。
- 吉利媒体按键只有建立过 CarPlay 媒体流才转发，保留 OneOS 标准键码识别和重复事件抑制。
- 单一“保存诊断报告”入口，手动选择保存位置，取消即取消；缺少选择器时明确询问是否使用默认位置。报告可直接查看和分享，不需要解锁，也不自动上传。
- 副屏识别保留 Android 11 窗口上下文、界面结果提示、持久化识别记录，以及同名副屏的精确 ID 选择。
- 保留覆盖升级签名和外部身份资源构建方式；Git 仓库不包含身份文件或签名密钥。

源码合并通过仓库 Android checks 验证；测试、Lint 和编译结果以对应提交的 Actions 为准，实车表现仍需新的诊断报告确认。
